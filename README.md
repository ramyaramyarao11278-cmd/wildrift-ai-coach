# ⚔️ LOLM AI 战术助手 (WildRiftAICoach)

专为 **《英雄联盟手游》(League of Legends: Wild Rift)** 打造的 Android 原生 **AI 视觉识屏 + 战术教练悬浮窗** App。

采用 Android 系统级 `MediaProjection` 屏幕捕获 + `SYSTEM_ALERT_WINDOW` 海克斯风格半透明悬浮窗 + OpenAI 兼容多模态大模型（Vision LLM），**100% 纯画面读取，不注入或修改任何游戏内存，安全防封**。

---

## ✨ 核心功能

1. **游戏内海克斯悬浮球 & 战术面板**
   - 平时吸附在屏幕左右边缘（半透明不挡操作、不抢摇杆焦点）。
   - 点击截屏分析瞬间，**自动隐身悬浮窗 140ms**，确保截取 100% 纯净无遮挡的选人/加载界面，随后立即恢复并流式（SSE）展示 AI 战术报告。
   - 自动适配手机竖屏（桌面）与横屏（进入英雄联盟手游）分辨率切换。

2. **三大实战模式一键触发**
   - **⚡ 选人 BP 分析**：识别我方与敌方已亮/已锁英雄头像、分路图标及双方 Ban 位，一针见血指出**我方阵容缺口**（如缺 AP、缺前排、缺开团），并推荐 **2~3 个最佳 Counter（克制）英雄** 及召唤师技能/符文微调建议。
   - **⚔️ 加载阵容深度分析**：识别 5v5 加载界面全部 10 名英雄对位、基石符文与召唤师技能，输出**前/中/后期强势期对比**、**我方核心赢点与团战集火目标**、以及**关键针对装提醒**（何时早做重伤、巨蛇之牙破盾、水银饰带、冰心/兰顿等）。
   - **🛡️ 局内计分板出装诊断**：局内点开计分板（查看双方 KDA、经济与已出装备）后点击，AI 自动识别敌方大爹威胁并推荐**下一件核心针对装备**与当前运营节奏。

3. **快捷战术追问标签 & 个性化视角**
   - 悬浮窗内置一键追问胶囊（无需局内打字）：`🎯 推荐Counter位`、`🩸 需要早做重伤/破盾吗?`、`🔥 1级团/首条小龙能接吗?`、`⚔️ 团战先杀谁?`。
   - 支持在主界面设置「我的常玩分路与关注重点」（如：`单排打野，重点告诉我前期刷野抓人路线`），AI 全程围绕你的位置视角给建议。

4. **内置主流多模态大模型预设（OpenAI 兼容接口）**
   - **通义千问 VL (阿里云百炼)**：`https://dashscope.aliyuncs.com/compatible-mode/v1`（推荐模型：`qwen-vl-max` 或 `qwen-vl-plus`，国内直连低延迟，中文英雄名识别极准）
   - **豆包视觉大模型 (火山引擎 Ark)**：`https://ark.cn-beijing.volces.com/api/v3`
   - **Google Gemini**：`https://generativelanguage.googleapis.com/v1beta/openai`（模型：`gemini-2.5-flash`）
   - **OpenAI / 第三方聚合中转站**：`https://api.openai.com/v1`（模型：`gpt-4o` / `claude-3-5-sonnet-latest`）
   - **智谱清言 GLM-4V**：`https://open.bigmodel.cn/api/paas/v4`（模型：`glm-4v-plus`）

## 📱 使用步骤

1. 将编译好的 APK (`app/build/outputs/apk/debug/app-debug.apk`) 发送到 Android 手机安装并打开。
2. 在 **「第二步：配置多模态视觉大模型 API」** 中选择平台预设，填入你的 **API Key**，点击 **「⚡ 测试 API 连通性」** 确认连接成功。
3. 点击 **「开启 AI 战术悬浮窗」**：
   - 首次使用会引导开启 **「显示在其他应用上层」**（悬浮窗权限）。
   - 在系统弹出的截屏授权框中选择 **「整个屏幕」** 并点击 **「立即开始」**。
4. 启动《英雄联盟手游》，在 **选人阶段** 或 **加载界面** 点击屏幕边缘的 **「AI 战术」悬浮球**，选择对应按钮即可实时查看 AI 深度战术建议！
